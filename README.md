### 👋 About me

Software developer based in Bucharest, Romania, and founder of [Uprise](https://uprise.ro). I specialise in high-performance WordPress and WooCommerce development: fast stores, clean integrations, no plugin bloat.

- 🔭 Currently building multiple high-performance, WooCommerce-powered stores
- 🇷🇴 Shipping **RomCommerce Lite**, a Romanian commerce layer for WooCommerce
- 🧾 Maintaining **FGSync Oblio**, an Oblio.eu invoicing integration
- ♻️ Built **Garanție SGR**, WooCommerce support for Romania's deposit-return scheme
- ⚙️ Day to day: ERP/API sync, server & system administration, Core Web Vitals tuning
- 💬 English · Română
